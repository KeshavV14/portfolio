# Mechatronics Portfolio

Welcome to my Mechatronics Portfolio! This website showcases my projects, background, and how to contact me.


## Setup Instructions

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/mechatronics-portfolio.git
   ```
2. Navigate to the project directory:
   ```
   cd mechatronics-portfolio
   ```
3. Open `index.html` in your web browser to view the portfolio.

## Features

- Responsive design for optimal viewing on various devices.
- A home screen with just my name and a short description.
- Tabs along the top for the Projects, Experience, About, and Contact pages, plus the resume.
- Colours and type modelled on [yigua.art](https://yigua.art).
